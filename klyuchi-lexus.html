Особливості ключів Lexus за поколіннями

  • Lexus до 2006 — простий чіп Texas 4C/4D67, програмування через OBD з пін-кодом.
  • Lexus 2006–2014 (G-chip, DST80) — RX III, IS II, GS III, LX 570 — smart-key з кнопкою START-STOP. Прив'язка вимагає правильного пін-коду.
  • Lexus 2014+ (H-chip, DST-AES) — NX, RX IV, IS III, ES VI/VII, UX — нове шифрування AES-128. Потрібне відповідне обладнання.
  • Lexus LS 460, LX 570 — окремий протокол із Smart-картою, складніше програмування.

Часті запитання про ключі Lexus

Скільки коштує smart-ключ Lexus RX?

Для RX 4-го покоління (2015+) з H-chip — від 6500 грн при наявності робочого ключа. При повній втраті — від 9000 грн через зчитування пін-коду.

Чи можете зробити ключ для Lexus без оригіналу?

Так. Для моделей до 2014 (G-chip) програмуємо через OBD з пін-кодом. Для H-chip (2014+) потрібно зчитати дані з блоку імобілайзера. Робота 2-4 години.

Чим Lexus відрізняється від Toyota?

Технічно — нічим, ті самі чіпи (DST, DST80, DST-AES) і протоколи. Відрізняються тільки корпусом ключа та лезом. Тому ціна і складність програмування ідентична Toyota відповідного року.

Що таке H-chip і DST-AES?

H-chip (Texas DST-AES) — нове покоління чіпа Toyota/Lexus з 2014 року. Має посилене шифрування AES-128, тому простіші програматори його не беруть. Потрібне обладнання типу Lonsdor K518, Autel IM608 з активацією або VVDI.
